# 公開前レビュー

確認日: 2026-09-23。対象は本リポジトリの全ソース、PowerShellスクリプト、テスト、ビルド設定、文書とGitへ追加するファイルです。コアとネイティブAPI、アプリ境界、導入スクリプトを分けて静的に読み、候補を再確認して修正しました。

## 修正内容

| 対象 | 確認した問題と修正 |
| --- | --- |
| 配信開始 | 解像度の記憶や状態表示の失敗を、完了済み配信準備の失敗として返さないよう修正 |
| 復旧 | 診断ログの書き込み失敗が画面復元を中断しないよう修正。復旧ジャーナルの保存は必須のまま |
| 入力 | 全ワイルドカードだけの復帰許可を拒否。Raw Input本文の型別の長さも検証 |
| ダウンロードと導入 | 導入時にもMSIとVDDアーカイブのSHA256を検証し、検証済みアーカイブを新しい場所へ展開して使用 |
| 汎用性 | GPU機種とNVENCの固定設定を除去。既存設定を維持し、必要時だけ引数で指定 |
| Windows設定 | 別アカウントの管理者資格情報による設定先・権限先の混同を拒否。再起動要求を表示 |
| 設定の保全 | パスの`$`を正規表現置換として解釈しない更新処理、他の開始コマンドの維持、衝突しないバックアップ名、原子的なUTF-8書き込み |
| 連携解除 | Sunshineの開始フックを除去するスクリプトを追加。残ったフックが次の配信を失敗させる状態での停止を防止 |
| 初期設定 | 未設定で仮想画面が1つなら自動選択。既存の入力設定は維持。既定構成ではSunshine画面GUIDの入力を不要化 |
| 画面の寿命 | 通常時は物理画面のみ、配信開始時に仮想化し、最終クライアント切断・開始失敗時に復元。再開による物理画面配信を防ぐ設定検証も追加 |
| 文書と公開対象 | ローカルIPや「このPCでは導入済み」という手順を整理。MITライセンス、導入・検証・セキュリティ文書、ソリューション、Windows CIを追加 |

## 検証

公開用コミットの作成前に`Build.ps1 -Publish`でビルド成功（警告0、エラー0）、回帰テスト58/58、セットアップ・構文チェック24件、コンソールなしCLI2件の成功を確認しました。PowerShell 5.1で検出したJSON配列と`File.Replace`の扱いの違いも修正しています。

実機の通常復帰、クラッシュ復旧、Moonlight接続・切断については[検証記録](deployment-report.md)に証拠の種類と範囲を分けて記載しました。導入スクリプトの全経路を新規Windows環境で試したわけではありません。

## 公開対象と残る範囲

ソースと文書を公開します。Gitへ追加した54ファイルについて、認証トークン・秘密鍵・導入機の識別情報のパターン、生成物の混入、UTF-8、文書内の相対ファイルリンクを検査し、該当する問題はありませんでした。これはパターン検査とレビューの結果であり、あらゆる秘密情報を機械的に検出できるという意味ではありません。

AppDataの設定、認証情報、端末識別子、生ログ、バックアップ、ダウンロードした第三者の配布物、EXE・DLLなどの生成物はGit対象外です。MITの許諾は本リポジトリのコードと文書に適用し、外部製品の許諾とは分けています。

レビューでは公開を止める必要のある未修正の重大な問題は確認していません。静的レビューと実施したテストの範囲での判断であり、脆弱性不存在の保証ではありません。異なるGPU・モニター接続変更・Windows再起動・WAN配信は追加確認が必要です。切断検知は対象Sunshineのログ形式に依存します。非公開の音声APIを使う補助スクリプトと、解除後も残すサービス操作権限については導入手順へ明記しています。
