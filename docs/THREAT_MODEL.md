# PseudoSleepの脅威モデル

対象はユーザーが公開を指定したPseudoSleepのソース、導入スクリプト、文書です。コードの所有・公開権限があることを前提とします。評価方法は静的レビューと通常のローカルビルド・回帰テストです。

## 保護対象と境界

- ローカル画面の復元可能性、保存済み画面構成、利用者の設定。
- Sunshineサービスの起動・停止権限と、管理者として実行する導入処理。
- 公開リポジトリに含めない認証情報、端末識別子、診断ログ、第三者のバイナリ。
- CLIから常駐アプリへの入口は、ユーザーSIDとセッションを含む名前付きパイプです。サーバーは`PipeOptions.CurrentUserOnly`を指定します。
- Sunshineの開始コマンドから受けるクライアントの幅・高さは設定検証を経由します。Sunshineのネットワーク認証と配信処理自体は本リポジトリの範囲外です。
- SunshineのローカルInfoログを切断監視に使用します。読み取り失敗・切り詰め・接続未確認では復元を優先します。既定の配信では仮想画面だけを有効にした後にキャプチャを開始します。
- 設定・復旧ジャーナルはユーザーのAppDataにあります。同一ユーザーによる任意のファイル変更に対する隔離は提供しません。

## 前提と対象外

信頼されたローカルユーザーが操作するWindows 11 x64の対話セッションを想定します。管理者や同一ユーザーのマルウェアからの防御、Sunshine/VDD内部の監査、侵入テスト、複数ユーザーの同時配信は対象外です。画面消灯はWindowsのロックやアクセス制御を意味しません。

## 確認事項と推奨事項

復旧処理、ネイティブAPIのバッファ境界、導入時の署名とパス、既存設定の保全、公開対象の機密情報を優先しました。ライセンスは所有者の指示によりMITです。レビュー結果は[公開前レビュー](publication-review.md)へ記録します。通常の自動テストと実機による受け入れ結果を区別し、全環境での動作や脆弱性不存在を保証する表現は使用しません。
